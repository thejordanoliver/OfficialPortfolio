Mobile App Design

Event Planner App

This planning experience focuses on making event setup, guest coordination, and event details easier to manage from a mobile-first interface.

Role UI/UX Design, Front-End Development
Tools Figma, React Native, PostgreSQL
Focus Event flows, mobile UI, data structure
Platform Mobile app concept

Overview

The project centers on a cleaner way to plan events from a phone, with screens that prioritize the next action, important event details, and clear status changes.

Design Focus

  • Simple event creation and editing flows.
  • Mobile layouts designed for repeated planning tasks.
  • PostgreSQL-backed thinking for structured event data.

Outcome

The result is a practical app direction with a clearer information hierarchy, stronger mobile patterns, and a more complete product story for planning events.
